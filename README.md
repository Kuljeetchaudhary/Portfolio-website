# Animated Portfolio 🚀

A personal portfolio website built using **React.js** and **Vite**, featuring smooth animations, interactive elements, and a responsive user interface.

🌐 **Live Website:** [Visit My Portfolio](https://kuljeet1portfolio.netlify.app)

---

## ✨ Features

- Interactive and animated user interface.
- Smooth scrolling navigation.
- Animated typing effects.
- GSAP-powered animations.
- Reusable React components.
- Organized project structure.

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

## 📦 Libraries & Packages Used

- **GSAP** – For creating smooth and interactive animations.
- **@gsap/react** – For integrating GSAP animations with React.
- **React Scroll** – For smooth scrolling and navigation.
- **React Type Animation** – For animated typing effects.

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd Animated_Portfolio
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the portfolio.

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

The generated production files will be available inside the `dist/` directory.

To preview the production build locally:

```bash
npm run preview
```
